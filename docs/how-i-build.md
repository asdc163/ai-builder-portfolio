# How I build

I start with one task a person needs to finish. Then I look at the decisions the software has to make, the information it needs and what should happen when that information is missing.

For a learning app, that meant keeping the dictionary and review flow usable without generation. For a community bot, it meant separating member participation from owner controls. The subscription system needed a clear path through partial, delayed and repeated payments.

I use AI for implementation and investigation. I still need to read the code, reproduce a failure and inspect the resulting behavior. When a product includes a model, I separate format checks from content quality and keep mock output out of provider measurements.

Handoff includes the awkward parts: ownership, restore instructions, unresolved states and the checks the next operator still has to run. Private operational details travel through the delivery channel, not the public case study.
