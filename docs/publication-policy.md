# Public portfolio policy

The commercial cases in this portfolio were rewritten for public reading. Their names are generic. The repositories contain authored documentation and conceptual diagrams only.

## Kept private

- Client names, original product branding, contracts, sale terms, pricing, revenue, costs, traffic, group sizes, and customer counts.
- Credentials, account identifiers, bot handles, payment destinations, server addresses, private endpoints, and operational configuration.
- Source archives, database contents, logs, message histories, screenshots from live customer systems, and original delivery bundles.
- Proprietary implementation details and private verification receipts.

## What a case study supports

A case explains the user problem, my work, selected engineering decisions, and the limits of recorded verification. Conceptual diagrams omit implementation and deployment details. They are not operational runbooks.

Historical validation is labelled as recorded evidence. A local test, simulator run, or engineering handoff does not establish current production operation, real payment settlement, regulatory approval, adoption, or commercial outcomes.

## Publishing changes

Review new text and diagrams before committing. Use an explicit file list and a new documentation-only repository; do not import a commercial project's Git history. Check links, secret-shaped strings, identifying terms, and business data before pushing, then read the public result back.

The absence of source files makes these documentation showcases. They do not grant access to or a license for the private applications. Repository documentation carries no open-source license unless one is explicitly added.

Report a suspected disclosure privately through [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/privately-reporting-a-security-vulnerability) if enabled on the affected repository. Do not reproduce sensitive material in a public issue.
